# Deploying to GitHub Pages

1. Create a new **public** repository on GitHub (e.g. `portfolio`).
2. Upload these three items to the repo root: `index.html`, `styles.css`, and the `assets/` folder (keep the folder structure — the résumé must stay at `assets/resume/Arham_Ahanaf_Resume.pdf`).
3. In the repo, go to **Settings → Pages**.
4. Under "Build and deployment," set **Source** to `Deploy from a branch`, branch `main`, folder `/ (root)`. Save.
5. Wait 1–2 minutes, then refresh — GitHub will show your live URL (something like `https://yourusername.github.io/portfolio/`).
6. Open that URL in an incognito/private window to confirm it loads with **no login or password prompt**.
7. Test it on your phone (or resize your browser window) to confirm it's readable and nothing overlaps.
8. Replace the video placeholder and the three project placeholder cards in `index.html` (see the `TODO` comments in the file), then re-upload the changed file to GitHub (it redeploys automatically).
9. Submit the live URL on Canvas, and in the **Comments** box type: `Targeting Track`.
